# Skills

Each folder is one [Agent Skill](https://agentskills.io/specification). `name` in YAML must match the folder.

| Skill | Use when |
|---|---|
| [maintain-agent-skills](maintain-agent-skills/SKILL.md) | Creating or validating skills |
| [cli-full-md-install](cli-full-md-install/SKILL.md) | CLI from `content/k{1,2}/full.md` |
| [fail-closed-restore-replay](fail-closed-restore-replay/SKILL.md) | Step failed; restore and replay |
| [manual-vs-auto-diff](manual-vs-auto-diff/SKILL.md) | Finished auto vs finished manual |
| [anonymous-mod-fixtures](anonymous-mod-fixtures/SKILL.md) | Tests/policy; no published titles |
| [local-desktop-gui-testing](local-desktop-gui-testing/SKILL.md) | Real Avalonia desktop |
| [full-build-install-validation](full-build-install-validation/SKILL.md) | Wizard select-all + ValidatePage |
| [headless-mod-download-automation](headless-mod-download-automation/SKILL.md) | Unattended archives |
| [cloud-agents-starter](cloud-agents-starter/SKILL.md) | Headless Cloud VM |

Do not add underscore folder names. `cloud_agent_starter` is not a skill.
