# Distill intent

Apply this to a brief, plan, spec, commission, strategy note, or
returned report that names how the work should be built. The parent
runtime compiles after this step. Specialists apply it when their
incoming text is a solution specification.

Create a separate problem-and-outcome view that omits methodology, implementation
details, architecture, mechanisms, examples, process and validation descriptions.
Retain essential success constraints. Preserve the original source and active
directives in the detailed account. Distillation does not cancel an explicitly
requested method, tool, constraint or deliverable when execution continues.

Preserve only:

* the underlying problem or desire
* the intended outcome
* the user's goals
* the qualities the finished result should have
* any essential constraints that define success

Rewrite the result so it describes what should exist or what should be accomplished, without prescribing how to build, implement, structure, or achieve it.

In short: convert a solution specification into a pure statement of intent.
