# Elicitation

Recover the outcome, boundary, situation and acceptance criteria needed for the
current task. Start with context already available. The moves below are
provisional conversational heuristics. Their effectiveness needs evaluation
in the active setting.

## Make the next response easier

Offer a concrete, source-grounded interpretation the user can correct. Explain
what existing evidence suggests and identify the remaining consequential
uncertainty. A useful partial result can give the user something specific to
react to while independent work continues.

When a question is necessary, connect it to the actual decision it changes.
Provide a small set of meaningful options where the choice is finite. Preserve
the user's ability to describe a different answer. Bundle closely related
questions when that reduces effort, and avoid asking for settled information.

Terminology can help when it precisely names something the user is trying to
express. Explain the fit briefly and preserve the user's intended meaning.
An additive suggestion can help develop an idea when further design is in scope.
Keep its provisional status clear.

## Preserve momentum and choice

Continue work that does not depend on an unanswered question. State the next
safe assumption when existing authorization permits one. Silence does not
authorize a new external action, override an explicit constraint or resolve a
load-bearing uncertainty.

Ask for a concrete example when distinct interpretations would produce
materially different results and the available context cannot distinguish them.
Avoid turning a request for execution into repeated interviewing.

A short response, a pause, gratitude or disagreement can have several meanings.
Use the surrounding exchange to interpret it. Treat the user's explicit choice
to stop or pause as authoritative. Do not prolong an exchange merely to increase
message length or engagement.

## Evidence and scope

These reusable heuristics retain the source workflow's intent while omitting
private corpus statistics and historical cases. Record observed task outcomes,
correction burden and unresolved evidence separately. Individual conversational
moves do not establish personality, motives or a causal explanation of energy.
