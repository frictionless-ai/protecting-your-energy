# Constraint channels

Route every constraint. Do not drop one.

| Channel | Owner |
|---|---|
| Task semantics | executor |
| Authority / boundaries | executor |
| Output contract | executor prompt and/or native verbosity/schema |
| Reasoning / effort | native effort knob when it exists |
| Cosmetic | primary agent |

- `use your best judgement` → authority
- `quickly` → effort knob
- `no essay` / `one liner` → output contract (what to keep: conclusion, evidence, caveat, next action)
- Persist only on `from now on` / `always` / `stop doing X` / `for the rest of this session`
