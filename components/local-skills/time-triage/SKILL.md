# Time triage

Recover current goals, commitments and relevant history. Assess each item from evidence. Avoid inferring character or motivation from an incomplete list.

- Deliberately deferred work has an evidenced competing priority. State the tradeoff and any actual deadline.
- Work awaiting proof needs a named uncertainty and the smallest sufficient check. Consider a provable subset while preserving required quality and the cost of leaving the work unavailable.
- Work awaiting execution needs a concrete smallest next action. Describe the observed state and let uncertainty about the reason remain visible.
- An unresolved reason remains unresolved. Seek recoverable context and continue independent authorized work.

For each item return the item, evidenced reason, concise wording the user can reuse and a next action when needed. Include confidence when the explanation is inferred. Respect obligations to other people, including replies, credit and corrections. Avoid rationalizing every delay or diagnosing the user. A private profile may provide context only within its authorization and supporting evidence.

Use dot-connect for shaping an idea after the user has selected it. Match audience and context when drafting an explanation for another person.
