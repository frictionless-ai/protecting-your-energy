# Private author-voice configuration

Keep the completed version in a private location and set `PYE_VOICE_PROFILE_DIR` to that directory.

## Author and audience

Record the intended author, audiences and contexts where each preference applies.

## Authentic examples

Add authorized source locations and exact examples. State what each example supports and any context-specific limits.

## Preferred moves

Record supported structure, vocabulary, tone, level of detail and treatment of uncertainty.

## Registers

Describe differences across personal replies, internal explanations, product copy and technical documentation when the evidence supports them.

## Corrections

Retain later explicit corrections and explain their scope. Keep unverified interpretations visible as proposals.

## Evaluation

Compare a draft with the intended meaning and audience. Counts and stylistic similarity alone cannot establish a faithful result.
