# Editing scope

Recover the requested audience and artifact before editing. UI chrome uses plain-ui-copy. Authored essays, internal explanations and requested personal-voice work can use voice-match. New drafts can use write-as-me.

A README may contain both product-facing explanation and technical instructions. Apply the user's intended audience and preserve the existing contract. Avoid forcing a personal register onto a machine-consumed plan, generated changelog or structured handoff.

Frontmatter such as `artifact_contract` can identify a machine contract. Read its owning workflow before changing it. A directory name alone cannot override an explicit user request.

Configured private register files describe author preferences for their stated scope. Recover later corrections and source context before treating them as permanent.
