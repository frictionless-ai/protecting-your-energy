# Review generated-writing conventions

Recover the user’s actual request and the affected artifacts. Review repetitive structures, filler, comment placement and unwanted workflow narration using plain-ui-copy, write-as-me or voice-match where appropriate.

Preserve required attribution, licenses, factual provenance, machine contracts and intentional product features. Names of agents, models or tools may be necessary when those capabilities are the product being documented. Treat each occurrence in its context.

For ordinary editing, operate on the requested working-tree content. Existing local history remains available for understanding ownership and prior work.

## Authorized history work

When the user explicitly requests a history rewrite, inspect repository ownership, forks, upstreams, active collaboration and unpublished changes. Recover existing authorization rather than asking again.

Prepare the exact affected paths and refs, preserve a backup reference and review how rewritten commits affect collaborators. Keep meaningful source changes and required human or license attribution. A clean copy edit does not justify replacing unrelated source blobs across history.

Use the repository's established history tooling when the action is authorized. Inspect the resulting refs and content. A force push requires current authorization for that external action. Missing ownership evidence remains unresolved.

## Evaluation

Check that wording changes preserve meaning and that metadata changes satisfy the specific request. Compare the actual diff with the authorized paths and refs. Preserve private writing profiles and review notes outside distributable source.
