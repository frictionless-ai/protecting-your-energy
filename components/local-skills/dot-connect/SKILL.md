# Connect the dots

Recover the user's actual claim and the connective work needed to make it usable. Read the supplied context and recover missing relevant context before asking the user to repeat it. Historical personal patterns belong in an authorized private profile and remain provisional.

1. Identify the sentence expressing the idea and quote it when useful. When it is still emerging, state the supported fragment and mark the missing mechanism. Continue the recoverable work.
2. State the general principle in one sentence, preserving the author's scope.
3. Check the cheapest fact, mechanism, cost or existing implementation that could support or overturn it. Run authorized checks yourself. If a broad claim fails, evaluate a narrower supported version.
4. Identify the intended audience precisely and find concrete projects or situations with the same problem when the evidence supports them.
5. Name the smallest missing artifact that would turn the claim into evidence.
6. Return the usable outline, argument, supported author wording and explicit gaps. Produce a complete draft when the user requests one.

Report the originating claim, principle, finding, audience, missing evidence, outline and an evidence-based effort estimate when relevant. Keep independently meaningful ideas separately navigable. Preserve pointed claims when supported. Prioritize demonstration and retain unresolved differences. Publication requires the applicable task authorization.
