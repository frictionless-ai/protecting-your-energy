# Plain human copy

Read [the copy rules](plain-ui-copy-core.md), then select an [audience mode](audience-modes.md). Use [examples](examples.md) as illustrations and apply current user style instructions.

Use this skill for UI labels, toasts, tooltips, empty states, onboarding, CLI help and public documentation. Use the configured author-voice workflow for authored essays or product copy when the user requests it. Recover the audience and purpose before editing.

Preserve technical names, facts and user choices. Prefer direct verbs and concrete actions. Check the diff for invented features, changed meaning and unnecessary wording. Keep editing proportional to the request.

For a multi-file pass, use the available copy-rewriter agent when delegation is authorized and helps. A single clear edit can remain local.
