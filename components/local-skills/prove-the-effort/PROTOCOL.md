# Independent claim review

Apply only to an authorized assessor of a complex design, disputed claim or plan.

Read the original evidence and derive an assessment before considering another agent's conclusion. Each finding names a path and location, actual command result or attributed source. Identify whether the evidence was read, executed, inherited or remains unavailable.

For a disagreement, name the deciding criterion and check. Reconcile changed evidence explicitly. A supported claim may hold. After three rounds, retain the unresolved issue and continue independent work. Delegate further assessment only when authorized.

Return concise findings with claim, evidence, verification status, verdict and what would change it. Preserve material uncertainty and recipient context. Implementation workers receive a plain bounded task and deliverable.
