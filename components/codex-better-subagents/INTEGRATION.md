# Optional worker-profile component

This Apache-2.0 component preserves four Claude worker prompts, four Codex worker profiles, a lean CLI profile, the routing guide, installer source, and public project documentation. The component's model names and pricing statements are inherited source configuration. Their current availability and costs require separate verification against the selected provider.

Worker profiles remain nested to preserve their original identities alongside the parent plugin's existing host-role variants. Importing this source does not change active routing, install host profiles, authorize delegation, enable a provider, or grant access to secrets. Existing task and host instructions govern actual delegation and permissions.

The optional installer previews paths by default and supports `--help`. `--apply` explicitly writes user-wide files with backups. It has not been applied during packaging. The original installer and its copyright remain preserved in the source checkout. Review profile conflicts and host-specific routing before a later installation.

The lean Codex worker profile disables plugins, apps, memories, and hooks. Selecting it changes the tools and context available to that worker. Supply the necessary task context and deliberately enable any required tools under the current host's supported configuration.

LICENSE and public author attribution are preserved. This component includes no credentials, private provider configuration, active model sessions, evaluation reports, or generated state.
