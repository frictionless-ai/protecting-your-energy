# Optional future-capability workflow

This component preserves the local plan, build and review skills, three
read-only advisory roles, policy, templates and source validator. Its MIT
license is retained. The local source manifest supplies no author or repository
identity, so the integration preserves that uncertainty.

Select this standalone component explicitly through a compatible host's local
plugin loading when deliberate future-capability work is requested. Its generic
skill names remain component-scoped. The root reconstruction workflow continues
to recover the user's expressed idea.

Historical validation results, research and private working material are outside
this distribution. Source guides that cite them retain historical context and
require the upstream source checkout for those artifacts.

The bundled validator checks the distributed structure by default. Its explicit
`--source-audit` option also checks historical evaluation cases and research
records when running against an original source checkout containing them.
