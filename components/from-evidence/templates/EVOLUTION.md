# Evolution — {{skill_name}}

Dated deltas only. One reusable rule per entry. Not a diary.

This file is a seed written by `from-evidence` build. The living copy is the
one next to the installed skill. Deltas here win over the base `SKILL.md`
when the skill is used. When a delta becomes default practice, `/evolve`
moves its example into dataset `{{dataset_name}}` and rebuilds; the rule then
lives in the regenerated `SKILL.md` and the entry is marked promoted.

## Format

```markdown
### YYYY-MM-DD
- rule: …
- why: …
- example: …
- promoted: no | YYYY-MM-DD
```
