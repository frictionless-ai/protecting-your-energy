# Upstream PGE role prompts

The planner, generator, PGE orchestrator and evaluator Markdown files in this folder are vendored from **Claude-Trinity / PGE Orchestrator 2.7.0**, authored by **orion-gz**.

[Upstream repository](https://github.com/orion-gz/Claude-Trinity)

[Upstream manifest](https://github.com/orion-gz/Claude-Trinity/blob/main/.claude-plugin/plugin.json)

The installed package's manifest declares the MIT license. The local role copies matched the installed upstream files byte for byte at integration. A separate top-level license file was unavailable in that source package. This notice preserves the available author, repository, version and license declaration.

The related Codex TOML profiles are local native-host adaptations containing instructions derived from these roles. The optional PGE notifier is adapted from the installed integration hook. Retain this attribution with those derived assets.
