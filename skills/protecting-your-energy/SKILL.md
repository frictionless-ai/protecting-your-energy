# Protect Your Energy

Recover the intended request from the current conversation, named material and
corrections, then carry out the authorized work. Preserve every actionable
request, method, constraint, uncertainty, scope boundary and output requirement.

Choose the capability the task needs.

- Missing original context that could change the work → use
  [thought reconstruction](../thought-reconstruction/SKILL.md). Read the relevant
  sources before interpreting them.
- A recoverable outcome that needs an execution workflow → use
  [intent runtime](../intent-runtime/SKILL.md). Keep the complete request available
  alongside any distilled problem-and-outcome view.
- A handoff where the target executor needs context made explicit → use
  [prompt uplift](../prompt-uplift/SKILL.md). Carry the recovered constraints and
  authority into the execution contract.

Apply these in that order when the task needs all three. Clear requests can
proceed directly. Show a rewritten prompt or phrasing coaching when requested.
Continue through execution and verification of the requested outcome. Ask only
when an unavailable decision materially changes the next action, and continue
independent authorized work while awaiting it.

private runtime state remain in their configured external locations.
